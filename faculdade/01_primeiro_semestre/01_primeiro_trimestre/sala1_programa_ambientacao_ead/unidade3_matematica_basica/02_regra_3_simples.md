# Regra de 3 Simples

## 🧠 1. O que é regra de 3 simples?

A **regra de 3 simples** é usada quando temos **duas grandezas relacionadas** e conhecemos três valores, mas precisamos descobrir um quarto valor.

Existem dois tipos:

* **Diretamente proporcionais**
* **Inversamente proporcionais**

---

# 📈 2. Grandezas diretamente proporcionais

São grandezas que **aumentam ou diminuem juntas**.

```text
Aumenta → Aumenta
Diminui → Diminui
```

### Exemplo

Se **3 bifes** rendem **8 porções**, quantas porções podem ser feitas com **16 bifes**?

| Bifes | Porções |
| ----: | ------: |
|     3 |       8 |
|    16 |       X |

Mais bifes → mais porções.

➡️ Portanto, são **diretamente proporcionais**.

### Fazendo o X

```text
3     8
16    X
```

Multiplicamos em cruz:

**16 × 8 = 3 × X**

**128 = 3X**

**X = 128 ÷ 3**

**X ≈ 42,66**

➡️ Resultado matemático: **aproximadamente 42,66 porções**.

📌 Em uma situação real, é necessário interpretar o resultado de acordo com o contexto.

---

# ✖️ 3. Como resolver uma regra de 3 direta?

Quando for **diretamente proporcional**, podemos fazer a multiplicação cruzada.

```text
A    B
C    X
```

Então:

**C × B = A × X**

Depois:

**X = (C × B) ÷ A**

### Exemplo rápido

```text
3 → 8
16 → X
```

**X = (16 × 8) ÷ 3**

---

# 🔄 4. Grandezas inversamente proporcionais

São grandezas que **se comportam de forma contrária**.

```text
Aumenta → Diminui
Diminui → Aumenta
```

### Exemplo

Se uma quantidade aumenta, mas a quantidade restante diminui, temos uma relação inversa.

No exemplo:

| ml |  % |
| -: | -: |
|  5 |  7 |
|  9 |  X |

Se usamos mais produto, a concentração restante diminui.

➡️ Portanto, são **inversamente proporcionais**.

---

# 🔀 5. Como resolver uma regra de 3 inversa?

Uma maneira simples é **inverter uma das colunas** antes de fazer a multiplicação em X.

Original:

| ml |  % |
| -: | -: |
|  5 |  7 |
|  9 |  X |

Invertendo a coluna dos ml:

| ml |  % |
| -: | -: |
|  5 |  X |
|  9 |  7 |

Agora podemos fazer o X:

**5 × 7 = 9 × X**

**35 = 9X**

**X = 35 ÷ 9**

**X ≈ 3,88%**

➡️ Resultado: **aproximadamente 3,88%**.

---

# ↔️ 6. Outra forma de resolver a inversa

Também podemos pensar pela multiplicação dos valores de cada linha.

```text
5 × 7 = 9 × X
```

Depois:

```text
35 = 9X

X = 35 ÷ 9

X ≈ 3,88%
```

📌 O importante é entender que, na relação inversa, **quando uma grandeza aumenta, a outra precisa diminuir**.

---

# ⚖️ 7. Diferença entre direta e inversa

Essa é a parte mais importante para resolver a questão.

## 📈 Diretamente proporcional

Uma aumenta e a outra também aumenta.

```text
⬆️ → ⬆️
⬇️ → ⬇️
```

### Exemplo

**Mais bifes → mais porções.**

---

## 🔄 Inversamente proporcional

Uma aumenta e a outra diminui.

```text
⬆️ → ⬇️
⬇️ → ⬆️
```

### Exemplo

**Mais produto utilizado → menor quantidade restante.**

---

# 📋 8. Resumo rápido

| Tipo        | O que acontece?   | Como pensar                         |
| ----------- | ----------------- | ----------------------------------- |
| **Direta**  | Aumenta → aumenta | As duas vão na mesma direção        |
| **Direta**  | Diminui → diminui | As duas vão na mesma direção        |
| **Inversa** | Aumenta → diminui | Uma vai para cima, outra para baixo |
| **Inversa** | Diminui → aumenta | Uma vai para baixo, outra para cima |

---

# 🎯 9. Como identificar rapidamente?

Antes de fazer qualquer conta, faça esta pergunta:

> **Se uma grandeza aumentar, o que acontece com a outra?**

### Se também aumentar:

➡️ **Diretamente proporcional**

```text
⬆️ → ⬆️
```

Pode fazer o **X normalmente**.

---

### Se diminuir:

➡️ **Inversamente proporcional**

```text
⬆️ → ⬇️
```

É necessário **inverter uma das colunas** ou utilizar a relação inversa.

---
