# Raciocínio Lógico

## 🧠 1. O que é raciocínio lógico?

**Raciocínio lógico** é uma forma de **organizar os pensamentos** para entender situações e resolver problemas.

A palavra **lógica** vem do grego **lógos**, relacionada à ideia de linguagem e pensamento racional.

Na prática, usamos conceitos e informações que já conhecemos para analisar uma situação nova.

### Exemplo

Quando aparece um problema, podemos pensar:

> "Já passei por uma situação parecida?"

> "O que foi feito naquela situação?"

> "Qual foi o resultado?"

Assim, usamos experiências anteriores para ajudar a tomar uma decisão.

---

# 🔎 2. Como resolver problemas?

Resolver um problema envolve **comparar a situação atual com situações que já conhecemos**.

Uma forma simples de pensar:

```text
SITUAÇÃO ATUAL
      ↓
Lembrar situações anteriores
      ↓
Analisar decisões tomadas
      ↓
Observar os resultados
      ↓
Pensar em uma possível solução
```

📌 **Para lembrar:**

> **Problema → analisar → comparar → pensar → decidir.**

---

# 🔄 3. Argumentos lógicos e paradoxos

Dentro do raciocínio lógico, podemos encontrar diferentes formas de pensar e chegar a conclusões.

Entre elas estão:

* **Paradoxos**
* **Argumentos dedutivos**
* **Argumentos indutivos**

---

# ⚠️ 4. O que é um paradoxo?

Um **paradoxo** é uma afirmação que apresenta uma **contradição ou situação aparentemente impossível**.

Ele pode colocar uma ideia contra ela mesma, dificultando determinar se ela é verdadeira ou falsa.

### Exemplo clássico

> **"Esta sentença é falsa."**

Se a sentença for verdadeira:

➡️ Então ela é falsa.

Se a sentença for falsa:

➡️ Então ela seria verdadeira.

Temos uma contradição.

📌 Por isso, um paradoxo não funciona como uma conclusão lógica comum.

---

# 💭 5. Paradoxos no dia a dia

Os paradoxos também podem aparecer como frases que apresentam ideias aparentemente contraditórias.

### Exemplos

> **"Precisei estudar muito para entender que não sei nada."**

A ideia parece contraditória, mas representa uma reflexão sobre o conhecimento.

---

> **"Ama tanto ao ponto de perder o amor."**

Existe uma contradição aparente entre amar muito e acabar perdendo aquilo que ama.

📌 **Para lembrar:**

> **Paradoxo = ideia que apresenta uma contradição e provoca reflexão.**

---

# 🧩 6. Argumentos lógicos

Um **argumento lógico** utiliza informações para chegar a uma **conclusão**.

Uma das formas de raciocínio utilizadas é o **silogismo**.

### Silogismo

O **silogismo** é um raciocínio formado por informações que levam a uma conclusão.

Ele pode ser:

* **Dedutivo**
* **Indutivo**

---

# 🎯 7. Silogismo dedutivo

No **raciocínio dedutivo**, partimos de uma **regra geral verdadeira** e aplicamos essa regra a um caso específico.

Se as premissas forem verdadeiras e o raciocínio estiver correto, a conclusão será **necessariamente verdadeira**.

### Estrutura

```text
REGRA + CASO = CONCLUSÃO
```

Ou:

```text
Todo A é B
C é A
Logo, C é B
```

📌 **Dica:**

> No raciocínio dedutivo, a conclusão é **certa**, desde que as premissas sejam verdadeiras.

---

# 💻 8. Exemplo de raciocínio dedutivo

Vamos substituir as letras:

* **A = técnico de TI**
* **B = trabalha com computador**
* **C = Laerte**

### Regra

> Todo técnico de TI trabalha com computador.

### Caso

> Laerte é técnico de TI.

### Conclusão

> Logo, Laerte trabalha com computador.

```text
REGRA
Todo técnico de TI trabalha com computador.

        +

CASO
Laerte é técnico de TI.

        ↓

CONCLUSÃO
Laerte trabalha com computador.
```

➡️ Se as duas premissas forem verdadeiras, a conclusão é **necessária**.

---

# 👥 9. Outro exemplo de dedução

Observe:

> João nasceu antes de Maria.

> Antônio nasceu antes de João.

Se Antônio nasceu antes de João e João nasceu antes de Maria:

➡️ **Antônio é mais velho que Maria.**

A conclusão é obtida a partir das informações anteriores.

---

# 🔬 10. Silogismo indutivo

No **raciocínio indutivo**, observamos vários exemplos ou situações e, a partir deles, criamos uma conclusão geral.

Porém, essa conclusão **não é uma certeza absoluta**.

Ela é apenas **provável**.

📌 **Dica:**

> **Indutivo = provável, não conclusivo.**

---

# 📚 11. Exemplo de raciocínio indutivo

Imagine que:

> João estudou e passou na prova.

> Maria estudou e passou na prova.

> Pedro estudou e passou na prova.

> Carlos estudou e passou na prova.

A partir desses exemplos, podemos pensar:

> **Quem estuda passa na prova.**

Mas essa conclusão não é necessariamente verdadeira para todas as pessoas.

Pode existir alguém que estude e não passe.

Por isso, uma conclusão melhor seria:

> **Quem estuda provavelmente terá mais chances de passar na prova.**

📌 **Indução = observar casos → encontrar um padrão → criar uma conclusão provável.**

---

# ⚖️ 12. Dedutivo × Indutivo

| Dedutivo                                               | Indutivo                       |
| ------------------------------------------------------ | ------------------------------ |
| Parte de uma regra geral                               | Parte de vários exemplos       |
| Aplica a regra a um caso                               | Procura um padrão nos casos    |
| Conclusão necessária                                   | Conclusão provável             |
| Se as premissas forem verdadeiras, a conclusão é certa | A conclusão pode estar errada  |
| **Regra → caso → conclusão**                           | **Casos → padrão → conclusão** |

---

# 🧠 13. Como memorizar?

### 🎯 DEDUTIVO

```text
REGRA
  ↓
CASO
  ↓
CONCLUSÃO
```

➡️ **Certeza**

**Todo A é B.**
**C é A.**
**Logo, C é B.**

---

### 🔬 INDUTIVO

```text
CASOS
  ↓
OBSERVAÇÃO
  ↓
PADRÃO
  ↓
CONCLUSÃO
```

➡️ **Probabilidade**

**João estudou → passou.**
**Maria estudou → passou.**
**Pedro estudou → passou.**

➡️ **Provavelmente estudar aumenta a chance de passar.**
