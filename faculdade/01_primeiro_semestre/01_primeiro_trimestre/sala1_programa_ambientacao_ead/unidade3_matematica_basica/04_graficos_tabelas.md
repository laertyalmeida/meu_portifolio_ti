# Raciocínio Lógico

## 🧠 1. O que é raciocínio lógico?

**Raciocínio lógico** é uma forma de **organizar os pensamentos** para entender situações e resolver problemas.

A palavra **lógica** vem do grego **lógos**, relacionada à ideia de pensamento e linguagem racional.

Na prática, usamos a lógica para:

* Entender uma situação;
* Comparar informações;
* Tomar decisões;
* Resolver problemas;
* Chegar a uma conclusão.

📌 **Para lembrar:**

**Raciocínio lógico = organizar o pensamento para chegar a uma conclusão.**

---

# 🔎 2. Como usamos o raciocínio lógico?

Quando aparece um problema, podemos comparar a situação atual com **situações que já conhecemos**.

Podemos pensar:

* Já passei por algo parecido?
* Qual decisão foi tomada?
* Qual foi o resultado?
* Posso usar esse conhecimento na situação atual?

### Exemplo

Se uma determinada estratégia funcionou anteriormente, podemos analisar se ela também pode funcionar no problema atual.

📌 Resolver problemas envolve **comparar conhecimentos anteriores com a situação atual**.

---

# 🧩 3. Resolver problemas

Diante de um problema, é importante analisar as informações antes de tomar uma decisão.

Uma forma simples de pensar é:

```text
PROBLEMA
   ↓
ANALISAR A SITUAÇÃO
   ↓
LEMBRAR EXPERIÊNCIAS ANTERIORES
   ↓
ANALISAR AS DECISÕES TOMADAS
   ↓
OBSERVAR OS RESULTADOS
   ↓
TOMAR UMA DECISÃO
```

---

# 🔄 4. Argumentos lógicos e paradoxos

Os **argumentos lógicos** são formas de organizar informações para chegar a uma conclusão.

Entre os assuntos relacionados à lógica estão:

* Paradoxos;
* Argumentos dedutivos;
* Argumentos indutivos;
* Silogismos.

---

# ⚠️ 5. Paradoxo

Um **paradoxo** é uma afirmação ou situação que apresenta uma **contradição ou conflito lógico**.

Ele pode criar uma situação em que não conseguimos definir facilmente se uma afirmação é verdadeira ou falsa.

### Exemplo clássico

> **"Esta sentença é falsa."**

Se a frase for **verdadeira**, então ela precisa ser falsa.

Se a frase for **falsa**, então ela acaba sendo verdadeira.

Isso cria uma contradição.

📌 Por isso, o paradoxo não funciona como uma conclusão lógica comum.

---

## 💭 5.1 Paradoxos no dia a dia

Algumas frases também podem apresentar ideias aparentemente contraditórias para provocar reflexão.

### Exemplos

> **"Precisei estudar muito para entender que não sei nada."**

A frase parece contraditória, mas transmite a ideia de que quanto mais aprendemos, mais percebemos o quanto ainda existe para aprender.

Outro exemplo:

> **"Ama tanto ao ponto de perder o amor."**

A frase apresenta uma ideia aparentemente contraditória para provocar reflexão.

📌 **Para lembrar:**

**Paradoxo = ideia que apresenta uma contradição ou situação difícil de resolver logicamente.**

---

# 🧠 6. Silogismo

**Silogismo** é uma forma de raciocínio usada para chegar a uma **conclusão a partir de informações anteriores**.

Um silogismo normalmente possui:

1. **Primeira premissa** → uma regra ou informação geral;
2. **Segunda premissa** → um caso específico;
3. **Conclusão** → resultado obtido a partir das duas premissas.

Podemos resumir:

```text
REGRA + CASO = CONCLUSÃO
```

---

# 🔵 7. Silogismo dedutivo

No **raciocínio dedutivo**, começamos com uma regra geral considerada verdadeira e aplicamos essa regra a um caso específico.

A conclusão será verdadeira **se as premissas forem verdadeiras e o raciocínio estiver correto**.

### Estrutura

```text
REGRA: Todo A é B.
CASO:  C é A.
CONCLUSÃO: C é B.
```

📌 **Dica:** na dedução, a conclusão é uma consequência lógica das premissas.

---

## 💻 7.1 Exemplo

Vamos substituir as letras:

* **A = técnico de TI**
* **B = trabalha com computador**
* **C = Laerte**

### Regra

> Todo técnico de TI trabalha com computador.

### Caso

> Laerte é técnico de TI.

### Conclusão

> Laerte trabalha com computador.

Podemos organizar:

```text
REGRA
Todo técnico de TI trabalha com computador.

       +

CASO
Laerte é técnico de TI.

       ↓

CONCLUSÃO
Laerte trabalha com computador.
```

📌 **Para lembrar:**

**Regra + caso → conclusão.**

---

## 👥 7.2 Outro exemplo

> João nasceu antes de Maria.

> Antônio nasceu antes de João.

Logo:

> Antônio é mais velho que Maria.

A conclusão foi obtida relacionando as informações apresentadas.

---

# 🟢 8. Silogismo indutivo

No **raciocínio indutivo**, observamos vários exemplos ou situações e, a partir deles, criamos uma conclusão geral.

A diferença é que a conclusão **não é uma certeza absoluta**.

Ela é uma conclusão **provável**, baseada nas observações.

📌 **Dica:**

**Indução = provavelmente.**

---

## 📚 8.1 Exemplo

Observe:

> João estudou e passou na prova.

> Maria estudou e passou na prova.

> Pedro estudou e passou na prova.

> Carlos estudou e passou na prova.

A partir dessas observações, podemos chegar à conclusão:

> **Quem estuda passa na prova.**

Porém, essa conclusão não é necessariamente verdadeira em todos os casos.

Uma forma mais correta de interpretar seria:

> **Quem estuda provavelmente tem mais chances de passar na prova.**

📌 Isso acontece porque estamos usando exemplos observados para chegar a uma conclusão geral.

---

# 🔵 Dedutivo × 🟢 Indutivo

| Tipo         | Como funciona                                   | Resultado          |
| ------------ | ----------------------------------------------- | ------------------ |
| **Dedutivo** | Parte de uma regra geral e aplica a um caso     | Conclusão lógica   |
| **Indutivo** | Observa vários casos e cria uma conclusão geral | Conclusão provável |

### Exemplo

**Dedutivo:**

> Todo A é B.
> C é A.
> Logo, C é B.

**Indutivo:**

> A aconteceu dessa forma várias vezes.
> B aconteceu dessa forma várias vezes.
> C aconteceu dessa forma várias vezes.
> Logo, provavelmente outros casos seguirão o mesmo padrão.

---

# 🧠 Para memorizar

### 🔵 DEDUTIVO

**Regra → Caso → Conclusão**

➡️ Parte do geral para o específico.

➡️ Se as premissas forem verdadeiras e o raciocínio estiver correto, a conclusão é necessária.

---

### 🟢 INDUTIVO

**Exemplos → Observação → Conclusão provável**

➡️ Parte de casos específicos para uma ideia geral.

➡️ A conclusão é **provável**, não uma certeza.

---

### ⚠️ PARADOXO

**Contradição → dificuldade para definir uma conclusão lógica.**

---

# ⭐ Resumo rápido

**Raciocínio lógico** → organizar pensamentos para resolver problemas.

**Resolver problemas** → analisar a situação e comparar com conhecimentos e experiências anteriores.

**Paradoxo** → apresenta uma contradição ou conflito lógico.

**Silogismo** → usa informações para chegar a uma conclusão.

**Dedutivo** → regra + caso = conclusão.

**Indutivo** → vários exemplos → conclusão provável.

### 🎯 Dica principal

Pergunte:

**Tenho uma regra geral e estou aplicando a um caso?**

➡️ **Dedutivo.**

**Estou observando vários casos para chegar a uma conclusão?**

➡️ **Indutivo.**

**A afirmação apresenta uma contradição?**

➡️ **Paradoxo.**
