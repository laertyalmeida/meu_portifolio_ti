# 💻 Computação I – História e Desenvolvimento da TI

## 1. Início da computação
- Necessidade de facilitar cálculos
- Evolução gradual das máquinas

## 2. Fundamentos
- Matemática
- Lógica
- Algoritmos
- Eletrônica
- Hardware
- Software

## 3. Primeiras máquinas
- Schickard → cálculo
- Pascal → soma e subtração
- Leibniz → operações mais complexas

## 4. Matemática e lógica
- Sistema binário → 0 e 1
- Lógica booleana → verdadeiro/falso

## 5. Século XX
- Turing → algoritmos e computabilidade
- Church → computabilidade
- Shannon → lógica + circuitos
- Von Neumann → programas e dados na memória

## 6. Gerações dos computadores
- 1ª → Válvulas
- 2ª → Transistores
- 3ª → Circuitos integrados
- 4ª → VLSI + microprocessadores
- 5ª → ULSI + IA

## 7. Evolução
- Menor tamanho
- Maior velocidade
- Maior capacidade
- Menor consumo
- Menor custo

## 8. Século XXI
- Computação distribuída
- Nuvem
- Dispositivos móveis
- IoT
- IA
- Computação quântica

## 9. Computação quântica
- Bit → computação tradicional
- Qubit → computação quântica
- Superposição
- Emaranhamento

## 10. Ideia central
- A computação evoluiu da necessidade de calcular
- Matemática + lógica → fundamentos
- Eletrônica → evolução do hardware
- Software → programas e processamento
- Redes + nuvem → sistemas distribuídos
- IA + computação quântica → novas fronteiras
