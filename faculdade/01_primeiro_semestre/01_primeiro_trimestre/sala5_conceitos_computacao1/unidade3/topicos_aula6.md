# Capítulo 6 — Álgebra de Boole e postulados

- **Álgebra de Boole**
  - Trabalha com `0` e `1`
  - 0 = falso/desligado/baixo
  - 1 = verdadeiro/ligado/alto
  - Simplificação de circuitos
  - Fatoração

- **Complementação**
  - `A = 0 → A̅ = 1`
  - `A = 1 → A̅ = 0`
  - Dupla negação: `A̿ = A`

- **Adição — OR**
  - `A + 0 = A`
  - `A + 1 = 1`
  - `A + A = A`
  - `A + A̅ = 1`

- **Multiplicação — AND**
  - `A × 0 = 0`
  - `A × 1 = A`
  - `A × A = A`
  - `A × A̅ = 0`

- **Propriedades**
  - Comutativa
    - `A + B = B + A`
    - `AB = BA`
  - Associativa
    - `A + (B + C)`
    - `A(B × C)`
  - Distributiva
    - `A(B + C) = AB + AC`

- **De Morgan**
  - 1º teorema:
    - `(AB)̅ = A̅ + B̅`
    - AND → OR
  - 2º teorema:
    - `(A + B)̅ = A̅B̅`
    - OR → AND
  - Sempre complementar os termos

- **Circuitos integrados**
  - Chips
  - Portas lógicas
  - Contadores
  - Codificadores
  - Decodificadores

- **Objetivo**
  - Simplificar expressões
  - Reduzir portas lógicas
  - Otimizar circuitos
  - Criar circuitos mais compactos
