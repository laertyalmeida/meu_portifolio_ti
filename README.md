# Meu Portfólio de TI

Este repositório contém a documentação da minha jornada de aprendizado em tecnologia.

O objetivo é registrar estudos, comandos, conceitos e laboratórios práticos realizados durante minha formação.

# Conteúdos estudados

Documentação dos meus estudos sobre controle de versão utilizando Git.

Conteúdos desenvolvidos até o momento:

* Introdução ao Git.
* Instalação e configuração do Git no Debian.
* Criação de repositórios.
* Commits e histórico de alterações.
* Branches e fluxo de trabalho.

# Ambiente utilizado

Este projeto está sendo desenvolvido e documentado em ambiente Debian Linux utilizando principalmente o terminal.

Ferramentas utilizadas:

* Debian Linux
* Terminal GNU/Linux
* Git para controle de versão
* Markdown para documentação
* Vim como editor de texto

Fluxo de desenvolvimento:

```text
Terminal Debian
      │
      ▼

      ▼

      │
      ▼
Git commit
      │
      ▼
GitHub
```
