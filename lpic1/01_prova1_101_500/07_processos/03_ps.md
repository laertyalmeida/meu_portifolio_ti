# 07 — Processos
## 03 — ps

### ps — Process Status (Status dos Processos)

O `ps` mostra informações sobre os **processos em execução**.

Comando básico:

    ps

Mostra principalmente os processos associados ao terminal atual.

---

### ps -ef

    ps -ef

Mostra uma lista mais completa dos processos do sistema.

- `-e` — every (todos os processos)
- `-f` — full (informações completas)

Exemplo:

    UID        PID  PPID  C STIME TTY          TIME CMD
    root         1     0  0 08:00 ?        00:00:02 systemd
    laerte    1250     1  0 09:10 pts/0    00:00:00 bash
    laerte    1387  1250  0 09:15 pts/0    00:00:00 ps -ef

Campos importantes:

| Campo | Inglês | Português |
|---|---|---|
| UID | User ID | ID do usuário |
| PID | Process ID | ID do processo |
| PPID | Parent Process ID | ID do processo pai |
| C | CPU usage | Uso de CPU |
| STIME | Start Time | Hora de início |
| TTY | Terminal | Terminal associado |
| TIME | CPU Time | Tempo de CPU |
| CMD | Command | Comando executado |

---

### ps aux

    ps aux

Outra forma muito comum de listar processos.

- `a` — all users (processos de todos os usuários)
- `u` — user-oriented (formato orientado ao usuário)
- `x` — include processes without terminal (incluir processos sem terminal)

Exemplo:

    USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
    root         1  0.0  0.1  ...   ...   ?        Ss   08:00   ... systemd
    laerte    1250  0.0  0.2  ...   ...   pts/0    Ss   09:10   ... bash

Informações importantes:

- `%CPU` → percentual de CPU usado
- `%MEM` → percentual de memória usada
- `VSZ` → memória virtual
- `RSS` → memória residente na RAM
- `STAT` → estado do processo
- `COMMAND` → comando executado

---

### ps -p — Process by PID (Processo pelo PID)

Para consultar um processo específico:

    ps -p 1250

- `-p` — process ID (selecionar pelo PID)

Também podemos definir quais informações mostrar:

    ps -p 1250 -o pid,ppid,user,stat,cmd

- `-o` — output (definir campos de saída)
- `pid` — ID do processo
- `ppid` — ID do processo pai
- `user` — usuário
- `stat` — estado
- `cmd` — comando

---

### ps -f — Full (Completo)

    ps -f

Exibe informações adicionais dos processos.

Exemplo:

    UID       PID  PPID  C STIME TTY          TIME CMD
    laerte   1250  1000  0 09:10 pts/0    00:00:00 bash

---

### Ver processos em formato de árvore

O `ps` também pode mostrar relações entre processos:

    ps --forest

A opção `--forest` organiza visualmente os processos em uma estrutura de árvore.

Exemplo:

    systemd
    └─bash
      ├─vim
      └─ps

Para uma visão específica:

    ps -ef --forest

---

### ⚠️ Atenção para a prova LPIC-1

Memorize principalmente:

    ps
    ps -ef
    ps aux
    ps -p PID
    ps -o campos

**`ps -ef`**
→ estilo tradicional/UNIX, mostra todos os processos com informações completas.

**`ps aux`**
→ estilo BSD, mostra processos de todos os usuários, inclusive sem terminal.

**PID**
→ identifica o processo.

**PPID**
→ identifica o processo pai.
