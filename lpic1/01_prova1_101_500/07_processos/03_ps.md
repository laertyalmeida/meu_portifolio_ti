# Processos

## 03 — ps

### ps — Process Status — Status dos Processos

O `ps` mostra informações sobre os processos em execução.

Uso básico:

    ps

Exemplo:

    PID TTY          TIME CMD
    1520 pts/0    00:00:00 bash
    1580 pts/0    00:00:00 ps

Por padrão, o `ps` mostra principalmente os processos associados ao terminal atual.

---

## Mostrar todos os processos

### ps -e

    ps -e

**`-e` — Every Process — Todos os Processos**

Mostra os processos de todos os usuários.

Também existe:

    ps -A

**`-A` — All — Todos**

---

## Formato completo

### ps -f

    ps -f

**`-f` — Full Format — Formato Completo**

Mostra informações adicionais, incluindo:

- UID — usuário
- PID — ID do processo
- PPID — ID do processo pai
- início
- terminal
- tempo de CPU
- comando

---

## Combinação muito usada

### ps -ef

    ps -ef

Mostra todos os processos em formato completo.

Exemplo:

    UID        PID  PPID  C STIME TTY          TIME CMD
    root         1     0  0 08:00 ?        00:00:02 /sbin/init
    laerte    1520  1400  0 10:20 pts/0    00:00:00 bash

Observe:

    PID  → processo
    PPID → processo pai
    CMD  → comando executado

---

## ps aux

Outra forma muito utilizada:

    ps aux

Aqui:

- `a` → processos de todos os usuários com terminal.
- `u` → formato orientado ao usuário.
- `x` → inclui processos sem terminal associado.

> `ps aux` usa opções no estilo BSD, por isso as opções aparecem sem `-`.

---

## Escolher as informações exibidas

### ps -o

**`-o` — Output Format — Formato de Saída**

Exemplo:

    ps -o pid,ppid,user,%cpu,%mem,cmd

Mostra somente os campos escolhidos.

| Campo | Significado |
|---|---|
| `pid` | PID — ID do processo |
| `ppid` | PPID — ID do processo pai |
| `user` | Usuário |
| `%cpu` | Uso de CPU |
| `%mem` | Uso de memória |
| `cmd` | Comando |

---

## Consultar um PID específico

### ps -p

**`-p` — Process ID — ID do Processo**

Exemplo:

    ps -p 1520

Podemos combinar com `-o`:

    ps -p 1520 -o pid,ppid,cmd

---

## Encontrar processos

O `ps` pode ser combinado com `grep`:

    ps aux | grep firefox

Isso procura `firefox` na saída do `ps`.

Outra opção:

    pgrep firefox

**pgrep — Process Grep — Localizar Processos**

O `pgrep` procura processos pelo nome ou outros critérios.

---

## Árvore de processos

O `ps` também pode mostrar relações entre processos:

    ps --forest

A opção:

**`--forest` — Forest — Árvore**

organiza visualmente os processos, mostrando a relação entre processos pais e filhos.

Exemplo simplificado:

    systemd
      └─ bash
          └─ sleep

---

## Principais opções

| Opção | English | Português |
|---|---|---|
| `-e` | Every Process | Todos os processos |
| `-A` | All | Todos |
| `-f` | Full Format | Formato completo |
| `-p` | Process ID | Selecionar PID |
| `-o` | Output Format | Formato de saída |
| `--forest` | Forest | Exibir árvore de processos |
| `a` | All with TTY | Processos de todos os usuários com terminal |
| `u` | User-oriented | Formato orientado ao usuário |
| `x` | No TTY | Incluir processos sem terminal |

---

## Comandos para memorizar

Ver processos atuais:

    ps

Todos os processos:

    ps -e

Todos + formato completo:

    ps -ef

Visão detalhada:

    ps aux

PID e PPID:

    ps -o pid,ppid,cmd

PID específico:

    ps -p 1520

Árvore:

    ps --forest

---

## Resumo LPIC-1

- `ps` → **Process Status — Status dos Processos**.
- `ps` → mostra processos associados ao terminal atual.
- `ps -e` → mostra todos os processos.
- `ps -f` → formato completo.
- `ps -ef` → todos os processos em formato completo.
- `ps aux` → visão ampla dos processos.
- `ps -o` → escolher os campos exibidos.
- `ps -p` → consultar um PID específico.
- `ps --forest` → visualizar processos em árvore.
- `PID` → identifica o processo.
- `PPID` → identifica o processo pai.
- `CMD` → mostra o comando associado ao processo.
