# CPU e Arquitetura

## CPU — Unidade Central de Processamento

A **CPU** é um componente eletrônico físico instalado na **placa-mãe**. É responsável por **buscar, interpretar e executar instruções**, realizando operações com dados.

---

## Arquitetura

A **arquitetura** define as regras e características que determinam **como a CPU funciona** e como ela entende e executa as instruções.

Ela define, por exemplo:

* Quais instruções a CPU consegue executar;
* Quais registradores existem;
* Como os dados são representados;
* Como a memória é endereçada;
* Como os componentes internos da CPU são organizados;
* Qual o tamanho das operações que a CPU consegue trabalhar.

---

## Instruções

São comandos que dizem à CPU **qual operação deve ser realizada**.

Exemplos:

* Realizar cálculos;
* Comparar valores;
* Mover dados;
* Acessar a memória;
* Realizar operações lógicas;
* Controlar o fluxo de execução de um programa.

---

## Registradores

São **pequenas áreas de armazenamento dentro da CPU**, extremamente rápidas.

Podem guardar temporariamente:

* Valores;
* Endereços;
* Resultados de operações;
* Informações necessárias para executar instruções.

---

## Memória

### RAM — Random Access Memory

É a **memória principal e temporária** do sistema.

Armazena programas e dados que estão sendo utilizados naquele momento.

### Cache

É uma memória **muito rápida**, próxima ou dentro da CPU.

Armazena dados e instruções que podem ser utilizados novamente, evitando que a CPU precise buscar tudo diretamente na RAM.

### SSD / HDD

São dispositivos de **armazenamento permanente**.

Guardam:

* Sistema operacional;
* Programas;
* Arquivos;
* Dados do usuário.

---

## Núcleos — Cores

Os **núcleos** são unidades de processamento dentro da CPU.

Uma CPU pode possuir vários núcleos, permitindo executar várias tarefas ao mesmo tempo, dependendo do sistema operacional e dos programas.

---

## Arquiteturas comuns no Linux

### x86 / x86-64

* **x86** → arquitetura tradicional de 32 bits.
* **x86-64** → extensão da arquitetura para 64 bits.
* A AMD desenvolveu a extensão x86-64, também chamada de **AMD64**.
* A Intel também utiliza essa arquitetura, conhecida como **Intel 64**.

### ARM / AArch64

ARM é uma família de arquiteturas baseada na filosofia **RISC**, que utiliza instruções mais simples e eficientes.

* **ARM 32 bits** → geralmente associado ao AArch32.
* **AArch64** → arquitetura ARM de 64 bits.
* Muito utilizada em celulares, dispositivos embarcados, computadores e servidores.

---

## 32 bits e 64 bits

Um bit pode assumir dois valores:

```text
0 ou 1
```

A quantidade de combinações aumenta conforme a quantidade de bits:

```text
2¹  = 2 combinações
2²  = 4 combinações
2³  = 8 combinações
...
```

Portanto:

```text
32 bits → 2³² combinações possíveis
64 bits → 2⁶⁴ combinações possíveis
```

A quantidade de bits está relacionada à capacidade de trabalhar com determinados **valores, registradores e endereços**.

> **Importante:** 64 bits não significa simplesmente que a CPU "executa 64 bits por vez". Uma arquitetura de 64 bits envolve vários aspectos do processador.

## Como a memória é endereçada

De forma simplificada:

```text
Programa
   ↓
Sistema Operacional
   ↓
Instruções + Dados
   ↓
Arquitetura define como serão tratados
   ↓
CPU busca e executa
   ↓
Registradores / Cache / RAM
```

A CPU utiliza **endereços de memória** para localizar onde estão os dados e as instruções necessárias.

---

## Organização interna da CPU

De forma simplificada:

```text
                 CPU
                  │
        ┌─────────┴─────────┐
        │                   │
Unidade de Controle      ULA / ALU
        │                   │
        │              Cálculos e
        │              operações lógicas
        │
  Registradores
        │
      Cache
```

### Unidade de Controle

Coordena a execução das instruções.

### ULA / ALU

**Unidade Lógica e Aritmética.**

Realiza:

* Cálculos;
* Comparações;
* Operações lógicas.

### Registradores

Armazenam temporariamente valores, endereços e resultados utilizados pela CPU.

### Cache

Armazena temporariamente dados e instruções utilizados com frequência para acelerar o processamento.

---

## Resumo do funcionamento

```text
BITS
 ↓
0 e 1

INSTRUÇÃO
 ↓
Código que representa uma operação

ARQUITETURA
 ↓
Define como a CPU interpreta essa instrução

CPU
 ↓
Busca → Interpreta → Executa

COMPONENTES DA CPU
 ↓
Controle + ULA + Registradores + Cache

MEMÓRIA
 ↓
RAM e armazenamento fornecem dados e instruções
```

### Para memorizar

> **A arquitetura define as regras, a instrução diz o que fazer e a CPU executa.**
