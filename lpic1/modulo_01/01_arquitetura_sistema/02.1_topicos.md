# BIOS / UEFI

1. **Firmware**

   * Função
   * Inicialização do hardware

2. **BIOS**

   * Basic Input/Output System
   * Funcionamento tradicional

3. **UEFI**

   * Unified Extensible Firmware Interface
   * Funcionamento moderno

4. **BIOS × UEFI**

   * Principais diferenças
   * MBR × GPT
   * Boot tradicional × UEFI

5. **POST**

   * Power-On Self-Test
   * Verificação do hardware

6. **Boot**

   * Processo de inicialização

7. **Bootloader**

   * Função
   * GRUB
   * Arquivos `.efi`

8. **MBR**

   * Master Boot Record
   * Particionamento tradicional

9. **GPT**

   * GUID Partition Table
   * Particionamento moderno

10. **Secure Boot**

    * Verificação de assinaturas
    * Segurança no boot

11. **NVRAM**

    * Entradas de boot
    * Configurações

12. **Ordem de inicialização**

    * SSD
    * USB

13. **Fluxo de inicialização**
