# BIOS / UEFI

## Firmware

**Firmware** é um software gravado em um dispositivo eletrônico que controla funções básicas do hardware.

No computador, o firmware é executado **antes do sistema operacional**.

Ele prepara o hardware e inicia o processo de inicialização do computador.

---

## BIOS

**BIOS — Basic Input/Output System**

É um firmware tradicional utilizado para iniciar o computador.

Suas principais funções são:

* Inicializar o hardware;
* Realizar o POST;
* Identificar dispositivos;
* Procurar um dispositivo de inicialização;
* Carregar o código de inicialização do sistema operacional.

A BIOS tradicional normalmente trabalha com:

* Particionamento **MBR**;
* Modo de inicialização baseado em código de boot;
* Limitações relacionadas ao hardware e aos discos modernos.

---

## UEFI

**UEFI — Unified Extensible Firmware Interface**

É o padrão moderno que substituiu a BIOS tradicional.

Também é um firmware responsável por inicializar o hardware e iniciar o sistema operacional.

Principais características:

* Suporte ao **GPT**;
* Suporte a discos maiores;
* Inicialização mais flexível;
* Suporte a **Secure Boot**;
* Pode possuir interface gráfica;
* Pode executar aplicações próprias;
* Armazena informações de configuração na **NVRAM**.

---

## BIOS × UEFI

| BIOS                               | UEFI                            |
| ---------------------------------- | ------------------------------- |
| Firmware tradicional               | Firmware moderno                |
| Geralmente utiliza MBR             | Geralmente utiliza GPT          |
| Mais limitado                      | Mais completo e flexível        |
| Boot baseado no código do MBR      | Boot através de arquivos `.efi` |
| Não possui Secure Boot tradicional | Pode utilizar Secure Boot       |
| Configuração mais simples          | Recursos mais avançados         |

> **Importante:** UEFI não é simplesmente uma "BIOS nova". É um padrão de firmware diferente, criado para substituir o modelo tradicional de BIOS.

---

## POST

**POST — Power-On Self-Test**

É o teste realizado durante a inicialização do computador.

Verifica se componentes básicos estão funcionando corretamente.

Exemplos:

* CPU;
* Memória RAM;
* Teclado;
* Dispositivos de armazenamento;
* Outros componentes essenciais.

De forma simples:

```text
Computador liga
      ↓
Firmware inicia
      ↓
POST
      ↓
Hardware é verificado
      ↓
Processo de boot continua
```

---

## Boot

**Boot** é o processo de inicialização do computador.

De forma simplificada:

```text
Energia
  ↓
Firmware
  ↓
POST
  ↓
Dispositivo de boot
  ↓
Bootloader
  ↓
Kernel
  ↓
Sistema operacional
```

---

## Bootloader

O **bootloader** é o programa responsável por iniciar o sistema operacional.

No Linux, um exemplo comum é o **GRUB**.

Em sistemas UEFI, o firmware procura um arquivo executável no formato **`.efi`** dentro da **EFI System Partition (ESP)**.

Exemplo simplificado:

```text
UEFI
 ↓
EFI System Partition
 ↓
Bootloader
 ↓
GRUB
 ↓
Kernel Linux
 ↓
Sistema operacional
```

---

## MBR × GPT

### MBR

**MBR — Master Boot Record**

É um padrão de particionamento mais antigo.

Características:

* Associado ao modo tradicional de BIOS;
* Possui limitações de tamanho e quantidade de partições;
* Guarda informações importantes no início do disco.

### GPT

**GPT — GUID Partition Table**

É um padrão de particionamento moderno.

Características:

* Normalmente utilizado com UEFI;
* Suporta discos muito maiores;
* Permite mais partições;
* Possui mecanismos de proteção e redundância das informações da tabela.

---

## Secure Boot

**Secure Boot** é um recurso do UEFI que ajuda a impedir que softwares não autorizados sejam executados durante o processo de inicialização.

De forma simples:

```text
UEFI
 ↓
Verifica assinatura do bootloader
 ↓
Assinatura válida?
 ├── Sim → continua o boot
 └── Não → pode bloquear a inicialização
```

Seu objetivo principal é aumentar a segurança do processo de boot.

---

## NVRAM

**NVRAM — Non-Volatile Random Access Memory**

É uma memória que mantém informações mesmo quando o computador é desligado.

Em sistemas UEFI, pode armazenar informações relacionadas à inicialização, como:

* Entradas de boot;
* Ordem de inicialização;
* Configurações do firmware.

Exemplo:

```text
NVRAM
 ↓
Entrada de boot
 ↓
EFI System Partition
 ↓
Bootloader
```

---

## Ordem de inicialização

O firmware possui uma **ordem de boot**, que determina onde o computador deve procurar um sistema para iniciar.

Exemplo:

```text
1. SSD
2. USB
3. Rede
```

Se o SSD possuir um sistema operacional inicializável, o firmware pode iniciar por ele.
