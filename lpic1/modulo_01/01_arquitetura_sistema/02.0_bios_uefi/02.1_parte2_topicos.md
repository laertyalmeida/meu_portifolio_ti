# BIOS / UEFI — PARTE 2

## 1. POST
- Power-On Self-Test
- Verificação inicial do hardware
- CPU, RAM, teclado, vídeo etc.

## 2. Firmware → Dispositivo de armazenamento
- BIOS/UEFI identifica os dispositivos
- Escolhe o dispositivo de boot
- Ordem de boot

## 3. BIOS + MBR
- BIOS procura o MBR
- MBR contém o código inicial do bootloader
- Limitações do MBR

## 4. UEFI + GPT
- UEFI trabalha normalmente com GPT
- UEFI procura a partição ESP
- ESP = EFI System Partition
- Bootloader fica na ESP

## 5. Bootloader
- GRUB
- Recebe o controle do firmware
- Apresenta/escolhe o sistema
- Carrega o kernel

## 6. Secure Boot
- Verificação de assinatura
- Impede boot de componentes não autorizados
- Relação com UEFI

## 7. Variáveis UEFI
- Configurações armazenadas pelo firmware
- /sys/firmware/efi/
- efibootmgr

## 8. BIOS/UEFI e Linux
- Como verificar se o sistema iniciou em BIOS ou UEFI
- Comandos:
  test -d /sys/firmware/efi && echo UEFI || echo BIOS
