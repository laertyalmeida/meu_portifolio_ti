# BIOS / UEFI — PARTE 1
## Fundamentos

### 1. O que é Firmware
- Software gravado no hardware.
- É executado antes do sistema operacional.
- Prepara o computador para iniciar.

### 2. BIOS
- Basic Input/Output System.
- Firmware tradicional/antigo.
- Responsável pela inicialização básica do computador.
- Faz o POST.
- Localiza um dispositivo de boot.
- No modo tradicional, trabalha com MBR.

### 3. UEFI
- Unified Extensible Firmware Interface.
- Substituiu o BIOS tradicional em computadores modernos.
- Mais moderno e flexível.
- Pode trabalhar com GPT.
- Utiliza a ESP para arquivos de inicialização.
- Pode utilizar Secure Boot.

### 5. MBR
- Master Boot Record.
- Fica no início do disco.
- Contém informações/código relacionados à inicialização.
- Está associado ao particionamento tradicional.
- Possui limitações de tamanho e quantidade de partições.

### 6. GPT
- GUID Partition Table.
- Esquema moderno de particionamento.
- Associado frequentemente ao UEFI.
- Suporta discos muito maiores.
- Não possui a mesma limitação de 4 partições primárias do MBR.

### 7. ESP
- EFI System Partition.
- Partição usada pelo UEFI.
- Normalmente FAT32.
- Guarda arquivos de inicialização EFI.
- No Linux, normalmente aparece como /boot/efi.

### 8. Secure Boot
- Recurso do UEFI.
- Verifica assinaturas dos componentes de boot.
- Ajuda a impedir a execução de componentes não autorizados durante a inicialização.

### 9. Boot

BOOT = inicialização.

É o processo que acontece desde:

ENERGIA
 ↓
FIRMWARE
 ↓
HARDWARE
 ↓
BOOTLOADER
 ↓
KERNEL
 ↓
SISTEMA OPERACIONAL

### 10. GRUB
- Bootloader muito utilizado no Linux.
- Pode apresentar o menu de sistemas.
- Escolhe o kernel.
- Carrega o kernel na memória.
- Passa parâmetros para o kernel.

### 11. Kernel
- Núcleo do sistema Linux.
- Assume o controle do hardware.
- Gerencia CPU, RAM, dispositivos, processos etc.

### IDEIA PRINCIPAL

BIOS/UEFI NÃO É O LINUX.

BIOS/UEFI = firmware responsável pela
inicialização inicial do computador.

GRUB = bootloader que inicia o sistema.

KERNEL = núcleo que assume o controle do computador.

SYSTEMD = inicia e gerencia os serviços do Linux.
