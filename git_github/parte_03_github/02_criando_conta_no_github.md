# Capítulo 02 — Criando uma Conta no GitHub

---

# Pré-requisitos

Antes de iniciar este capítulo é recomendado compreender a diferença entre Git e GitHub.

---

# Neste capítulo você aprenderá

* Como criar uma conta no GitHub.
* A importância do perfil do desenvolvedor.
* Como confirmar a conta por e-mail.
* Como acessar a plataforma pela primeira vez.

---

# Por que criar uma conta no GitHub?

Para utilizar os recursos do GitHub é necessário possuir uma conta.

Ela permitirá:

* criar repositórios remotos;
* armazenar projetos na nuvem;
* colaborar com outros desenvolvedores;
* compartilhar seu portfólio;
* contribuir com projetos de código aberto (*Open Source*).

O perfil do GitHub também funciona como um cartão de visitas para desenvolvedores, reunindo projetos, histórico de contribuições e informações públicas.

---

# Criando a conta

Acesse o site oficial do GitHub:

**https://github.com**

Na página inicial, clique em **Sign up**.

Em seguida, informe:

* endereço de e-mail;
* senha;
* nome de usuário (*Username*).

Após preencher os dados, siga as instruções apresentadas na tela.

---

# Glossário

| Termo    | Tradução           | Significado                                             |
| -------- | ------------------ | ------------------------------------------------------- |
| Sign up  | Cadastrar-se       | Criar uma nova conta                                    |
| Sign in  | Entrar             | Acessar uma conta existente                             |
| Username | Nome de usuário    | Identificador público da conta                          |
| Password | Senha              | Credencial utilizada para autenticação                  |
| Email    | Correio eletrônico | Endereço utilizado para cadastro e recuperação da conta |

---

# Confirmando o e-mail

Após concluir o cadastro, o GitHub enviará uma mensagem para o endereço de e-mail informado.

Abra a mensagem e clique no link de confirmação.

Essa etapa valida a conta e libera todos os recursos da plataforma.

---

# Primeiro acesso

Depois de confirmar o e-mail, acesse novamente:

```text
https://github.com
```

Clique em **Sign in** e informe:

* nome de usuário ou e-mail;
* senha.

Após a autenticação, você será direcionado para a página inicial do GitHub.

---

# O que aconteceu internamente?

Ao criar sua conta, o GitHub registra suas informações e cria um perfil público associado ao seu nome de usuário.

A partir desse momento, você poderá criar repositórios, participar de projetos colaborativos e sincronizar seus repositórios locais utilizando o Git.

Seu histórico de contribuições também começará a ser registrado conforme você enviar alterações para o GitHub.

---

# Atenção

Escolha seu nome de usuário com cuidado.

Ele fará parte do endereço público do seu perfil.

Exemplo:

```text
https://github.com/seu-usuario
```

Se possível, utilize um nome profissional e de fácil identificação.

---

# Resumo

Neste capítulo você aprendeu como criar uma conta no GitHub, confirmar o endereço de e-mail e realizar o primeiro acesso à plataforma. Também compreendeu a importância do perfil do GitHub como ambiente de hospedagem de repositórios e apresentação profissional.
