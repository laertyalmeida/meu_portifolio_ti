# Conceito teórico

## O que é Git?

O **Git** é um sistema de **Controle de Versão** (*Version Control*) distribuído.

Seu objetivo é registrar todas as alterações realizadas em arquivos e projetos, permitindo acompanhar sua evolução ao longo do tempo.

Com o Git é possível:

* registrar modificações realizadas em arquivos;
* recuperar versões anteriores;
* trabalhar em equipe sem perder alterações;
* criar diferentes linhas de desenvolvimento utilizando branches;
* manter um histórico completo do projeto.


**Como funciona**
Você começa algo, vai fazendo aos poucos ou até mesmo futuramente depois de pronto, você muda, (uma nova versão, daí o nome versionamento), você mantém a atualização em um local principal e todas as versões anteriores para consulta futuras ou até mesmo recomeçar em alguma versão mais antiga você também mantem salvas para consultar ou reusar quandonquiser.

Hoje o Git é uma das ferramentas mais utilizadas no desenvolvimento de software, infraestrutura, administração de sistemas e documentação técnica.

---

# O que é Controle de Versão?

Imagine que você escreveu um documento e salvou várias cópias com nomes como:

```text
projeto.txt
projeto_final.txt
projeto_final_acabando.txt
projeto_final_acabando2.txt
```
Depois de alguns dias, você não lembra qual arquivo contém a versão correta.

O Git resolve esse problema.

Em vez de criar vários arquivos com nomes diferentes, ele registra todas as alterações em um histórico organizado.

Assim, você pode voltar para qualquer versão anterior sempre que necessário.

# Por que aprender Git, se eu posso salvar no comoutador meus trabalhos?

Mesmo trabalhando sozinho, o Git oferece diversas vantagens.

Ele permite acompanhar SUA EVOLUÇÃO, recuperar alterações, testar novas ideias com segurança e organizar melhor seus projetos.

Além disso, o Git é uma habilidade bastante valorizada no mercado de tecnologia e faz parte do dia a dia de desenvolvedores, administradores de sistemas, profissionais de DevOps e analistas de infraestrutura.

---

# Onde o Git é utilizado?

O Git pode ser utilizado em diversos tipos de projetos, por exemplo:

* desenvolvimento de software;
* scripts em Shell Script ou Python;
* automações;
* documentação técnica;
* infraestrutura como código;
* estudos pessoais (praticamente tudo);
* projetos colaborativos.

Praticamente qualquer arquivo que sofra alterações ao longo do tempo pode ser versionado com Git.
