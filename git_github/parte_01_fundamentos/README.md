# Parte 01 — Fundamentos do Git

Esta parte apresenta os conceitos básicos do Git e os primeiros passos para trabalhar com controle de versão.

---

# Conteúdos estudados

* O que é Git.
* Instalação do Git no Debian.
* Configuração da identidade do usuário.
* Criação de um repositório.
* Criação e acompanhamento de arquivos.
* Área de Trabalho (*Working Tree*).
* Área de Preparação (*Staging Area*).
* Commits.
* Consulta do histórico.
* Comparação de alterações com `git diff`.
* Arquivo `.gitignore`.
* Renomeação e remoção de arquivos.
* Restauração de alterações com `git restore`.
* Consulta detalhada de commits com `git show`.
* Fluxo básico de trabalho com Git.
* Desafio prático para revisar os conhecimentos da Parte 1.

---

# Principais comandos

```bash
git init
git config
git status
git add
git commit
git log
git diff
git restore
git mv
git rm
git show
```

Também foi estudado o arquivo:

```text
.gitignore
```

---

# Objetivo

Compreender como o Git funciona localmente e aprender a acompanhar, revisar, preparar, registrar e recuperar alterações em um projeto.
