# Parte 01 — Fundamentos do Git

Esta parte apresenta os conceitos fundamentais do Git e os primeiros passos utilizando controle de versão.

---

# Conteúdos estudados

- Introdução ao Git.
- Instalação no Debian.
- Configuração de identidade.
- Criação de repositórios.
- Commits.
- Histórico.
- Restauração de arquivos.

---

# Objetivo

Compreender como o Git funciona localmente e aprender a registrar a evolução de um projeto.
