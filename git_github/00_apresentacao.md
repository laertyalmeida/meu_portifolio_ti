# Apresentação

Seja bem-vindo ao **Guia de Estudos Git e GitHub**.

Este material foi desenvolvido durante minha jornada de aprendizado com o objetivo de registrar conhecimentos e, ao mesmo tempo, facilitar o aprendizado de outras pessoas.

A proposta desta documentação é apresentar cada assunto de forma simples, objetiva e progressiva.

Ao longo dos capítulos você encontrará conceitos, comandos e exemplos práticos, sempre procurando explicar o motivo de cada recurso existir antes de mostrar sua utilização.

---

# Como utilizar este material

Embora cada capítulo possa ser consultado individualmente, recomenda-se seguir a sequência da documentação.

Cada novo capítulo utiliza conhecimentos apresentados anteriormente.

---

# Padrão da documentação

Todos os capítulos seguem a mesma estrutura:

- Tempo estimado de leitura;
- Nível de dificuldade;
- O que será aprendido;
- Conceito teórico;
- Exemplos práticos;
- Curiosidade;
- O que foi aprendido;
- Boas práticas;
- Resumo;
- Próximo capítulo.

Esse padrão facilita a leitura e torna o aprendizado mais organizado.

---

# Convenções utilizadas

Sempre que um termo técnico em inglês aparecer pela primeira vez, seu significado será apresentado em português.

Exemplos:

| Inglês | Português |
|---------|-----------|
| Repository | Repositório |
| Branch | Ramificação |
| Commit | Registro permanente |
| Working Directory | Diretório de Trabalho |
| Clone | Clonar |
| Push | Enviar alterações |
| Pull | Buscar e integrar alterações |
| Merge | Mesclar |

---

# Filosofia da coleção

Esta documentação foi construída seguindo alguns princípios:

- compreender antes de executar;
- aprender antes de decorar;
- praticar cada conceito;
- documentar todo o aprendizado;
- utilizar exemplos simples;
- compartilhar conhecimento.

O objetivo é desenvolver uma base sólida, permitindo compreender o funcionamento do Git de maneira natural.

---

Este projeto está em constante desenvolvimento.

Novos capítulos serão adicionados conforme o avanço dos estudos, mantendo sempre o mesmo padrão de organização.
