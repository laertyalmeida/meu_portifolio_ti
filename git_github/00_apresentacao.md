# Apresentação

Bem-vindo à coleção **Git e GitHub — Guia de Estudos**.

Esta documentação foi desenvolvida para ensinar Git e GitHub de forma simples, prática e progressiva.

Cada capítulo apresenta um único conceito, explicando sua finalidade e demonstrando sua aplicação por meio de exemplos práticos. Dessa forma, o aprendizado acontece passo a passo, permitindo compreender o funcionamento do Git de maneira natural.

Sempre que um novo comando for apresentado, seu significado também será explicado, facilitando a associação entre o termo em inglês e sua função no Git.

O objetivo desta coleção não é apenas ensinar comandos, mas ajudar você a compreender como o Git funciona e por que cada recurso existe.

---

# Como utilizar esta coleção

Os capítulos foram organizados em uma sequência de aprendizado.

Recomenda-se estudar um capítulo por vez e realizar todos os exemplos práticos antes de prosseguir para o próximo.

Embora seja possível consultar capítulos específicos, seguir a ordem proposta facilitará a compreensão dos conceitos e do funcionamento do Git.

---

# Evolução da coleção

Esta coleção está em constante desenvolvimento.

Novos capítulos serão adicionados conforme o avanço dos estudos, mantendo o mesmo padrão de organização, linguagem e abordagem didática.

O objetivo é construir um material completo, que possa servir como referência para estudantes e profissionais que desejam aprender Git e GitHub desde os conceitos fundamentais até os recursos mais avançados.
